# ShawtySlayz

ShawtySlayz is a premium fashion e-commerce experience built for an Instagram-first clothing brand.

The project focuses on strong visual presentation, responsive product browsing, branded editorial content, and a smooth front-end shopping experience.

## Features

- Responsive fashion storefront
- Product browsing and product presentation
- Shopping cart functionality
- Conceptual checkout and order flow
- Branded editorial sections
- Instagram-inspired visual direction
- Smooth scrolling and motion effects
- Mobile-friendly navigation and layouts

## Built With

- Next.js
- React
- TypeScript
- CSS
- Framer Motion
- Lenis

## Project Scope

This project is a front-end e-commerce concept created for portfolio and demonstration purposes.

The checkout and order experience is conceptual and is not connected to a production payment or back-end order system.
